# 最近朗读正文折叠与展开

## 目标

让“最近朗读”中的长正文默认保持紧凑：正文超过 160 个字符时，仅显示前 160 个字符和省略号；用户可按条目查看全文并再次收起。

## 非目标

- 不更改最近朗读的保存内容、排序、三条上限或存储位置。
- 不向日志、UserDefaults 或其他持久化位置写入展开状态。
- 不改变朗读、语音、辅助功能、剪贴板、快捷键或权限行为。
- 不改菜单栏中的单行预览。

## 交互与视觉

- 每条记录独立维护当前窗口会话内的展开状态，以记录 ID 区分。
- 正文长度不超过 160 个字符时显示全文且不显示控制按钮。
- 长正文默认显示前 160 个字符和“…”；蓝色“查看全部”按钮紧跟摘要，按窄窗口宽度自然换行。
- 点击“查看全部”后显示完整正文，按钮改为“收起”。
- 点击“收起”恢复默认摘要。
- 内容高度变化使用约 0.2 秒的 ease-in-out 动画。
- 来源与时间仍位于按钮下方；左侧图标维持固定宽度，不因文本或按钮换行而被压缩。

## 实现边界

- 提取纯 Core 展示辅助逻辑，负责判定是否截断并产出摘要文字，供 XCTest 覆盖。
- `RecentReadingsView` 仅管理 SwiftUI 展开状态与渲染；不直接读写历史存储。
- 新增的 Core 文件纳入现有 SwiftPM target；不修改 `Package.swift`。

## 测试

- 等于或短于阈值：不截断、摘要等于原文。
- 长于阈值：判定为可折叠、摘要恰好为前 160 个字符加省略号。
- UI 构建由完整 Xcode Debug build 验证；SwiftPM 全量测试覆盖 Core 行为。

## 验收

- 三条记录分别展开或收起时互不影响。
- 长正文不会使卡片默认占满可滚动区域。
- 收起/展开不写入任何历史数据，重新打开界面回到默认折叠。
